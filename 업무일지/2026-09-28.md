# 2026-09-28 업무일지

## 1. 오늘 한 일 요약

- MapWebApp 7.0의 현장 상태 기준을 하나로 정리해 공개 반영했고, 12지역 계측자료·보고서·이관본의 정합성을 확인했다.

## 2. 세부 작업 및 결과

- `모두 사용중` 77개소를 별도 상태가 아닌 `계측 불가` 사유로 통합해, 지도·필터·범례·팝업·CSV 기준을 완료 958개와 계측 불가 674개, 총 1,632개로 맞췄다.
- 12지역 목포·해남 80개소 자료를 기존 측정항목 구조에 맞춰 5개 항목별 80개씩, 총 400개 사본으로 정리했다. 원본·사본의 해시와 크기가 모두 일치했고 누락·불일치·이미지 오류·빈 CSV·ZLR 유입은 없었다.
- THD 상위 10% Excel 복구본의 필터 참조 4개를 바로잡고 실제 Excel에서 15시트·14워크시트가 경고 없이 열리는 것을 확인했다.
- 7개 지역 560개소 기준 분석 PPT를 보완하고, CP단 전도노이즈 분석과 12지역 파형 2쪽을 추가·교체했다. 여수·광양 6개 지점 42개 조건 추가 분석은 전압 THD 평균 6.45%, 전압 H3 평균 6.14%였으며 42건 모두 전압 THD 5%·H3 3%를 넘었다.
- 계측자료 이관본은 15,086개 파일·10,811,364,634 bytes를 다시 대조해 해시 일치를 확인했다.

## 3. 근거가 되는 대화·파일·커밋·시간

- MapWebApp: 하위 저장소 커밋 `269a1f5`가 `MapWebApp_7.0.html`과 기준 CSV를 반영했다. 공개 Chrome에서 지도·타일·마커, 상태 수량, CSV 재가져오기 후 완료 958·계측 불가 674·기존 모두 사용중 사유 77개 유지, 페이지 오류 0건을 확인했다.
- 공개 MapWebApp HTML·CSV는 캐시 우회 주소에서 표식·행 수와 로컬 기준 정규화 SHA-256 `4095DA...B4728` 일치를 확인했다.
- PPT는 전체 렌더·패키지 무결성을 확인했으며, 여수·광양 추가 분석 반영본은 실제 PowerPoint 재열기까지 확인했다.

## 4. 미완료/다음 할 일

- MapWebApp 실제 휴대폰 Chrome 검증과 새 노트북에서의 이관본 실제 복원은 아직 수행하지 않았다.
- CP단 전도노이즈가 전압·전류 왜곡을 유발하거나 증가시킨다는 인과 근거는 현재 자료에서 확인하지 못했다. SOC와 시간대 영향도 분리되지 않았다.
